## L1 orchestration (`SKILL.md`, `l1-orchestration/`)

**Current state (2026-10-25)**

- Data folder (2026-10-28): the SKILL.md body runs `l4-tools-guards/scripts/data-dir.py --data-dir '${user_config.data_dir}'` and uses its one output line as `<data folder>` for popups, `projects.txt`, `active-index.json` and `--data-dir "<data folder>"` on every script call. The Intake popup for a task outside git recommends the data folder as a real path.
- SKILL.md and the phase files call the check before anything leaves (`secret-scan.py`) and the retrospective. The retrospective (`accept.md`) runs in this order: tally (`gate-report.py tally` → `gate-tally.md`), interpretation by `my-agent:gate-analyst` (→ `gate-report.md`), copy (`gate-report.py copy`), raising improvements (`feedback.py`) (2026-10-26).

**Dependence on external behavior**

- After compaction, only the first 5,000 tokens of the skill are attached again. Claude Code 2.1.322 counts them as characters: it keeps the first 5,000 × 4 = 20,000 characters minus a marker (read from the installed program on 2026-11-10; not documented, so it may change). SKILL.md stays under 12,500 characters (`test_skill_md`), so all of it is attached again. The text runs about 2.6 characters per token on Opus 5.5, not 4: the old 16,000-character budget was 6,053 tokens.
- Codex puts the whole SKILL.md text into the conversation at every call of the skill (three times in one recorded session, 2026-11-05) and reads the other rule files through `Bash` with an output token budget (default 10,000; the model set 5,000 in recorded sessions). Several files in one command were cut, so `hosts.md` says one rule file per command, and every file L1 reads in one go stays under 11,500 characters (12,000 for the procedure files until 2026-11-16).
- `${CLAUDE_PLUGIN_ROOT}` in the skill body is replaced, but variables inside phase files read with Read are not. SKILL.md tells L1 to replace them. The skill text uses `${CLAUDE_PLUGIN_ROOT}` only (the skill is `skills/my-agent/SKILL.md`, so the skill folder is not the plugin folder).
- `$CLAUDE_CODE_SESSION_ID` is available in the main session's Bash (F27). The `session:` in `.active` and the `step:` lines use this value.
